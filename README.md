# William Mulvaney — Personal Website

Welcome to the source for [williammulvaney.com](https://williammulvaney.com), the personal site of William Mulvaney. This site highlights my work as a podcast host, entrepreneur, software engineer, and writer.

##  Features

- **Podcast Hub** – Explore *The Willpower Podcast* with full episode feed, previews, and links to Spotify, Apple Podcasts, YouTube, and Amazon.
- **Newsletter** – Weekly insights on discipline, mindset, and self-growth, integrated via Substack.
- **Coaching Services** – Life coaching for fitness and dating, with testimonials and integrated payment.
- **About Me** – My story, core values, and current projects including ProCal, MyCoach AI, and Complete Canine.

## Tech Stack

- **Frontend**: React + Vite  
- **Styling**: Custom CSS (Tailwind-inspired)  
- **Hosting**: GitHub Pages

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```


## Philosophy
The purpose of this site is to share all of the things I'm working on with the world outside of my day job.
